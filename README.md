# admrul_data

**행정규칙류**(행정규칙·학칙·공단정관·공공기관)를 조문·링크·별표까지 Markdown 으로 담습니다.

`temporal_law` 파이프라인이 수집해 자동으로 커밋하는 **미러 저장소**입니다. (원본은 Postgres `lawdb` · 손으로 편집하지 마세요)

## 구조

```
{문서종}/{문서명}/
  ├─ {문서명}.md      조문 본문 (인라인 링크)
  ├─ {문서명}.json    같은 내용의 구조화 데이터
  └─ 별표/ 별지/ 첨부파일/ 본문이미지/
```

문서종 = 행정규칙 · 학칙 · 공단정관 · 공공기관.
