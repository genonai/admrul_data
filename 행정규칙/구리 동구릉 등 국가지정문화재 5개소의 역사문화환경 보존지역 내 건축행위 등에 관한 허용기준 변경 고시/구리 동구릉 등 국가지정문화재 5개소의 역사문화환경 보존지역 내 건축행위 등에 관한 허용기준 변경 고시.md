# 구리 동구릉 등 국가지정문화재 5개소의 역사문화환경 보존지역 내 건축행위 등에 관한 허용기준 변경 고시
> 고시 · 행정규칙 · 시행 2017-05-08 · 공포 2017-05-08 · 제정

### 전문
1. 고 시 명 : 「구리 동구릉」등 국가지정문화재 5개소의 역사문화환경 보존지역 내 건축행위 등에 관한 허용기준 변경 고시 2. 고시사항가. 대상문화재![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29804121)나. 관련근거ㅇ 문화재보호법 제13조, [제35조제1항제2호](https://www.law.go.kr/법령/문화재보호법/제35조)ㅇ 문화재보호법 시행령 [제21조의2제2항](https://www.law.go.kr/법령/문화재보호법%20시행령/제21조의2)ㅇ 문화재보호법 시행규칙 [제2조의2](https://www.law.go.kr/법령/문화재보호법%20시행규칙/제2조의2)다. 기준의 적용ㅇ 본 허용기준은 [「문화재보호법」제13조제4항 및 제6항](https://www.law.go.kr/법령/문화재보호법/제13조)과 [같은 법 시행령](https://www.law.go.kr/법령/문화재보호법%20시행령) [제21조의2제2항제1호](https://www.law.go.kr/법령/문화재보호법%20시행령/제21조의2)의 행위를 대상으로 한정하며, 그 이외의 사항에 대해서는 현행과 같은 국가지정문화재 현상변경 등 행위 처리절차에 따라 처리함ㅇ 본 허용기준 범위 내 행위는 [「문화재보호법」 제13조제2항](https://www.law.go.kr/법령/문화재보호법/제13조), 제6항에 따라 역사문화환경 보존지역에서 지정문화재의 보존에 영향을 미칠 우려가 없는 행위이므로 문화재 영향검토를 생략하고, 지방자치단체에서 자체 처리함라. 역사환경 보존지역 내 건축행위 등에 관한 허용기준ㅇ 세부내용 별첨자료 참조ㅇ 문화재별 현상변경 허용기준 도면- 문화재청 홈페이지(www.cha.go.kr) : 행정정보 > 법령정보 > 고시- 문화재공간정보(GIS)서비스(http://gis-heritage.go.kr) : 알림마당 > 현상변경 허용기준 3. 기준시행일 : 관보 고시일 4. 연 락 처가. 문화재청ㅇ 문화재청 문화재활용국 궁능문화재과 : 전화 042-481-4617 / 팩스 042-481-4709- 주소 : (우 35208) 대전광역시 서구 청사로 189 정부대전청사 1동- 홈페이지 : http://www.cha.go.kr나. 지방자치단체ㅇ 서울시 역사문화재과 : 전화 02-2133-2627 / 팩스 02-2133-1062- 주소 : (우 04515) 서울특별시 중구 덕수궁길 15 서소문청사 1동 4층ㅇ 경기도 문화유산과 : 전화 031-8008-4771 / 팩스 031-8008-3339- 주소 : (우 16444) 경기도 수원시 팔달구 효원로 1(매산로 3가)ㅇ 구리시 문화예술과 : 전화 031-550-2069 / 팩스 031-550-2803- 주소 : (우 11954) 경기도 구리시 아차산로 439 (교문동, 구리시청)ㅇ 파주시 문화예술과 : 전화 031-940-5831 / 팩스 031-940-4359- 주소 : (우 10932) 경기도 파주시 시청로 50(파주시청)ㅇ 광진구 문화체육과 : 전화 02-450-7592 / 팩스 02-450-1689- 주소 : (우 05026) 서울특별시 광진구 자양로 117 광진구청
