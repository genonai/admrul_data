# 「부안 죽막동 유적」 국가지정문화재(사적) 지정
> 고시 · 행정규칙 · 시행 2017-10-19 · 공포 2017-10-19 · 제정

### 전문
1. 고 시 명 : 「부안 죽막동 유적」 국가지정문화재(사적) 지정 2. 지정 문화재가. 지정종별 및 번호 : 사적 제541호나. 문화재 명칭 : 부안 죽막동 유적(扶安 竹幕洞 遺蹟, Archaeological Site in Jukmak-dong, Buan)다. 소 재 지 : 전북 부안군 변산면 적벽강길 54 일원(격포리 산33-3번지 일원)라. 지정면적 : 문화재구역 16필지 21,284㎡* 지번별 면적조서 : 붙임 참조마. 관리단체 : 전라북도 부안군 3. 지정사유ㅇ 부안 죽막동 유적은 고대 동아시아의 해양문화와 국제교류를 보여주는 제사유적으로 발굴조사 결과 백제 이후 통일신라, 고려, 조선 시대까지 다양한 시기의 유물이 출토되어 해양 제사문화의 변천과정을 보여주는 중요한 유적임. 4. 지정일자 : 관보 고시일 5. 지형도면 : “문화재공간정보서비스(http://www.gis-heritage.go.kr)”의 ‘알림마당 -지형도면 고시’ 참조 6. 참고사항가. [「토지이용규제기본법」 제8조](https://www.law.go.kr/법령/토지이용규제기본법/제8조)에 따른 문화재구역의 지형도면은 “문화재공간정보서비스(http://www.gis-heritage.go.kr)”의 ‘알림마당-지형도면 고시’ 에서 확인할 수 있으며, 문화재청   보존정책과 및 전라북도 부안군 문화관광과에서 출력된 도면을 열람할 수 있음.나. 관계기관 연락처ㅇ 문화재청 보존정책과 : 전화 042-481-4842/팩스 042-481-4849- 주    소 : (우 35208) 대전광역시 서구 청사로 189 정부대전청사 1동- 홈페이지 : http://www.cha.go.krㅇ 전라북도 문화유산과 : 전화 063-280-3147/팩스 063-280-2539- 주    소 : (우 54968) 전라북도 전주시 완산구 효자로 225- 홈페이지 : http://www.jeonbuk.go.krㅇ 부안군 문화관광과 : 전화 063-580-4711/ 팩스 063-580-4454- 주 소 : (우 56305) 전라북도 부안군 부안읍 당산로 91- 홈페이지 : http://www.buan.go.kr 붙임 : 「부안 죽막동 유적」 사적 지정 지번별 면적조서 1부.
