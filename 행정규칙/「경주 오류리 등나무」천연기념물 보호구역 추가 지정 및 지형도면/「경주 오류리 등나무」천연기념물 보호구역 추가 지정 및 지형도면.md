# 「경주 오류리 등나무」천연기념물 보호구역 추가 지정 및 지형도면
> 고시 · 행정규칙 · 시행 2017-11-08 · 공포 2017-11-08 · 일부개정

### 전문
1. 고 시 명 : 「경주 오류리 등나무」천연기념물 보호구역 추가 지정 및 지형도면 2. 고시사항가. 대상문화재 : 천연기념물 제89호 「경주 오류리 등나무」ㅇ 소 재 지 : 경상북도 경주시 현곡면 오류리 525번지 등나. 보호구역 추가 지정 면적 : 313㎡(2필지)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=32178585)다. 추가지정 후 보호구역 면적 : 2,097㎡(5필지)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=32178586)라. 보호구역 추가 지정 사유ㅇ 경주 오류리 등나무 보호구역과 연접하여 비닐하우스가 위치하고 있어 문화재 조망을 가리고, 경관을 저해하고 있으므로 보호구역을 추가 지정하여 주차장, 편의시설 확충 등 주변 정비를 통한 문화재 보존·관리 및 경관을 개선하고자 함마. 관리단체 : 경주시바. 지형도면 : 붙임과 같음 3. 추가 지정일 : 관보 고시일 4. 특기사항 : 토지이용규제기본법 [제8조](https://www.law.go.kr/법령/토지이용규제기본법/제8조)에 따른 지형도면 등은 문화재공간정보(GIS)서비스(http://www.gis­heritage.go.kr)에서 열람이 가능하고, 문화재청 천연기념물과와 경주시청 문화재과에서 출력된 도면을 열람하실 수 있습니다. 5. 연락처가. 문화재청ㅇ 주  소 : (우)35208 대전광역시 서구 청사로 189ㅇ 연락처 : 문화재청 천연기념물과 (전화) 042-481-4988, (전송) 042-481-4999ㅇ 홈페이지 : http://www.cha.go.kr, 전자메일 litston@korea.kr나. 지방자치단체ㅇ 주  소 : (우)38102 경상북도 경주시 양정로 260ㅇ 연락처 : 경주시청 문화재과 (전화) 054-779-6111, (전송) 054-760-7405ㅇ 홈페이지 : http://www.gyeongju.go.kr, 전자메일 fivesenses@korea.kr
