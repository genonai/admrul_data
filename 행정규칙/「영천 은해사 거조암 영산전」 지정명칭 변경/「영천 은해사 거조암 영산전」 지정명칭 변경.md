# 「영천 은해사 거조암 영산전」 지정명칭 변경
> 고시 · 행정규칙 · 시행 2021-03-31 · 공포 2021-03-25 · 제정

### 전문
1. 고 시 명 : 「영천 은해사 거조암 영산전」 지정명칭 변경가. 대상 문화재 : 국보 영천 은해사 거조암 영산전ㅇ 소 재 지 : 경상북도 영천시 청통면 거조길 400-67나. 변경 내용ㅇ 현행 : 영천 은해사 거조암 영산전(永川 銀海寺 居祖庵 靈山殿)ㅇ 변경 : 영천 거조사 영산전(永川 居祖寺 靈山殿)다. 변경 사유ㅇ ‘거조암(居祖庵)’의 창건 당시 명칭은 알 수 없지만 문헌 기록과 실증 자료를 통해 고려 시대부터 19세기 말까지 ‘거조사(居祖寺)’ 명칭을 사용하였고 사지 내 발굴조사를 통해 확인된 불전, 탑지를 보면 암자가 아닌 상당히 넓은 사역의 대중사찰 여건을 갖추고 있음에 따라, 지정명칭을 영천 거조사 영산전(永川 居祖寺 靈山殿)으로 변경 2. 고 시 일 : 관보 고시일 3. 연 락 처가. 문화재청ㅇ 문화재청 유형문화재과 : 전화 042-481-4916/팩스 042-481-4939- 주    소 : (우 35208) 대전광역시 서구 청사로 189 정부대전청사 1동- 홈페이지 : http://www.cha.go.kr나. 지방자치단체ㅇ 경북도청 문화유산과- 전화 : 054-880-3168 / 팩스 : 054-880-2949- 주소 : (우 36759)경상북도 안동시 풍천면 도청대로 455ㅇ 영천시 문화예술과 : 전화 054-330-6354/팩스 054-330-6668- 주소(우 38856) 경상북도 영천시 시청로 16,(문외동)- 홈페이지 : http://www.yc.go.kr
