# 서해 배타적경제수역내 골재채취단지 관리계획 변경승인
> 고시 · 행정규칙 · 시행 2016-12-30 · 공포 2016-12-30 · 일부개정

### 전문
1. 골재채취단지의 명칭 : 서해 중부 배타적경제수역 골재채취단지 2. 골재채취단지 관리자 : 한국수자원공사 3. 골재채취단지의 위치 및 면적![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=28379199)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=28379203) 4. 골재의 부존량(단위 : 천㎥)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=28379205) 5. 연도별 채취예정물량 : 총 62,250천㎥□ 변경 전(단위 : 천㎥)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=28379207)□ 변경 후(단위 : 천㎥)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=28379208) 6. 골재채취단지 지정기간![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=28379210) 7. 골재채취허가계획□ 변경 전(단위 : 천㎥)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=28379211)□ 변경 후(단위 : 천㎥)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=28379213)※ 총 채취량 범위 내에서 연도별 채취량을 변경·운영하되, 광구별 연간 채취량은 300만㎥ 이내, 단지전체 1,200만㎥(300만㎥×4개 광구) 이내로 운영
