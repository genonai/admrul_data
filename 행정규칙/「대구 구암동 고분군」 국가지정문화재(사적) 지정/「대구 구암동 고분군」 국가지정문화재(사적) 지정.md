# 「대구 구암동 고분군」 국가지정문화재(사적) 지정
> 고시 · 행정규칙 · 시행 2018-08-07 · 공포 2018-08-07 · 제정

### 전문
1. 고 시 명 : 「대구 구암동 고분군」 국가지정문화재(사적) 지정 2. 지정 문화재가. 지정종별 및 번호 : 사적 제544호나. 문화재 명칭 : 대구 구암동 고분군(大邱 鳩岩洞 古墳群), Ancient Tombs in Guam-dong, Daegu)다. 소 재 지 : 대구광역시 북구 구암동 392번지 일원라. 지정면적 : 문화재구역 50필지 428,509㎡* 지번별 면적조서 : 붙임 참조마. 관리단체 : 대구광역시 북구 3. 지정사유ㅇ 대구 구암동 고분군은 함지산 서쪽 능선에 360기의 봉분으로 구성된 대규모 고분군이며, 5~6세기 팔거평야를 중심으로 성장했던 신라 지역세력의 수장층 무덤으로 수혈식석곽 위에 봉분을 돌로 쌓은 독특한 축조양식을 보여주고 있어 역사적· 학술적 가치가 높은 유적임. 4. 지정일자 : 관보 고시일 5. 지형도면 : “문화재공간정보서비스(http://www.gis-heritage.go.kr)”의 ‘알림마당 -지형도면 고시’ 참조 6. 참고사항가. [「토지이용규제기본법」 제8조](https://www.law.go.kr/법령/토지이용규제기본법/제8조)에 따른 문화재구역의 지형도면은 “문화재공간정보서비스(http://www.gis-heritage.go.kr)”의 ‘알림마당-지형도면 고시’ 에서 확인할 수 있으며, 문화재청   보존정책과 및 대구광역시 북구 관광자원개발과에서 출력된 도면을 열람할 수 있음.나. 관계기관 연락처ㅇ 문화재청 보존정책과 : 전화 042-481-4842/팩스 042-481-4849- 주    소 : (우 35208) 대전광역시 서구 청사로 189 정부대전청사 1동- 홈페이지 : http://www.cha.go.krㅇ 대구광역시 문화예술정책과 : 전화 053-803-3756/팩스 053-803-3879- 주    소 : (우 41911) 대구광역시 중구 공평로 88, (동인동1가, 대구광역시청)- 홈페이지 : http://www.daegu.go.krㅇ 대구광역시 북구 관광자원개발과 : 전화 053-665-4326/ 팩스 053-665-4329- 주 소 : (우 41590) 대구광역시 북구 옥산로 65, 관광자원개발과(침산동)- 홈페이지 : http://www.buk.daegu.go.kr
