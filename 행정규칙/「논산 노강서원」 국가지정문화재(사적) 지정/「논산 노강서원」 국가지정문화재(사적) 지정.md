# 「논산 노강서원」 국가지정문화재(사적) 지정
> 고시 · 행정규칙 · 시행 2017-08-31 · 공포 2017-08-31 · 제정

### 전문
1. 고 시 명 : 「논산 노강서원」 국가지정문화재(사적) 지정 2. 지정 문화재가. 지정종별 및 번호 : 사적 제540호나. 문화재 명칭 : 논산 노강서원(論山 魯岡書院, Nogangseowon Confucian Academy, Nonsan)다. 소 재 지 :  충청남도 논산시 광석면 오강리 227라. 지정면적 : 문화재구역 1필지 3,666㎡, 보호구역 6필지 3,713㎡* 지번별 면적조서 : 붙임 참조마. 관리단체 : 노강서원 3. 지정사유ㅇ 논산 노강서원은 윤황, 윤문거, 윤선거, 윤증 등 호서지역 소론계의 대표적 인물들을 배향하였으며, 1871년 서원철폐령에도 훼철되지 않은 47개 서원 중 한 곳으로, 전학후묘식 배치로 공간의   위계성을 유지하는 서원 건축의 특성을 잘 보여주고 있어 역사적ㆍ학술적 가치가 높음. 4. 지정일자 : 관보 고시일 5. 지형도면 : “문화재공간정보서비스(http://www.gis-heritage.go.kr)”의 ‘알림마당 -지형도면 고시’ 참조 6. 참고사항가. [「토지이용규제기본법」 제8조](https://www.law.go.kr/법령/토지이용규제기본법/제8조)에 따른 문화재구역의 지형도면은 “문화재공간정보서비스(http://www.gis-heritage.go.kr)”의 ‘알림마당-지형도면 고시’ 에서 확인할 수 있으며, 문화재청 보존정책과 및 충청남도 논산시 문화예술과에서 출력된 도면을 열람할 수 있음.나. 관계기관 연락처ㅇ 문화재청 보존정책과 : 전화 042-481-4842/팩스 042-481-4849- 주    소 : (우 35208) 대전광역시 서구 청사로 189 정부대전청사 1동- 홈페이지 : http://www.cha.go.krㅇ 충청남도 문화재과 : 전화 041-635-3917/팩스 041-635-3087- 주    소 : (우 32255) 충청남도 홍성군 홍북면 충남대로 21, 충남도청- 홈페이지 : http://www.chungnam.netㅇ 논산시 문화예술과: 전화 041-746-5412/ 팩스 041-746-5399- 주 소 : (우 32916) 충청남도 논산시 시민로 210번길 9, 문화예술과- 홈페이지 : http://www.nonsan.go.kr
