# 국가지정문화재 천연기념물 지정 및 지형도면 고시(진주 정촌면 백악기 공룡·익룡발자국 화석산지)
> 고시 · 행정규칙 · 시행 2021-09-29 · 공포 2021-09-29 · 전부개정

### 전문
1. 고시명 : 국가지정문화재 천연기념물 지정 및 지형도면 고시 2. 고시내용○ 지정종별 및 지정번호 : 국가지정문화재(천연기념물 제566호)○ 지정명칭 : 진주 정촌면 백악기 공룡ㆍ익룡발자국 화석산지- 한자 : 晉州 井村面 白堊紀 恐龍ㆍ翼龍발자국 化石産地- 영문 : Tracksite of Cretaceous Dinosaurs and Pterosaurs in Jeongchon, Jinju○ 소재지 : 경상남도 진주시 정촌면 예하리 1408-1번지○ 문화재지정구역 : 17,500㎡(지번목록 및 지형도면 : 붙임 1.)○ 지정사유- 단일 지역에서 공룡과 익룡의 발자국 화석을 비롯하여 다양한 척추동물의 발자국 화석들이 밀집되어 산출된 드문 사례로 우리나라 백악기 척추동물발자국화석을 대표할만한 산지임.○ 지정근거: 문화재보호법 시행령 [제11조](https://www.law.go.kr/법령/문화재보호법%20시행령/제11조) 제1항 국가지정문화재(천연기념물)의 지정기준- 천연기념물 지정기준 제3호 : 지질ㆍ광물ㆍ지형(나. 지질시대와 생물의 역사 해석에 관련된 주요 화석과 그 산지)○ 문화재관리단체 : 경상남도 진주시 3. 지정일: 관보 고시일 4. 특기사항: 토지이용규제기본법 [제8조](https://www.law.go.kr/법령/토지이용규제기본법/제8조)에 의거한 문화재지정구역에 대한 지형도면은 문화재공간정보서비스(http://www.gis-heritage.go.kr)에서 열람이 가능하며, 문화재청 천연기념물과와 해당 자치단체 문화재 담당과에서 출력된 도면을 열람할 수 있습니다. 5. 연락처가. 문화재청 천연기념물과 : 전화 042-481-4984 / 팩스 042-481-49991) 주  소 : (우 35208) 대전광역시 서구 청사로 1892) 인터넷 : http://www.cha.go.kr / 전자메일 : sjh1010@korea.kr나. 경상남도 진주시 문화예술과 : 전화 055-749-3678 / 팩스 055-749-74021) 주  소 : (우 52857) 경상남도 진주시 영천강로68번길 222) 인터넷 : http://www.jinju.go.kr / 전자메일 : thumbwon@korea.kr
