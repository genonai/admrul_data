# 남해 배타적경제수역내 골재채취단지 관리계획 변경승인
> 고시 · 행정규칙 · 시행 2016-10-17 · 공포 2016-10-17 · 일부개정

### 전문
1. 골재채취단지의 명칭 : 남해 배타적경제수역 내 골재채취단지 2. 골재채취단지 관리자 : 한국수자원공사 3. 골재채취단지의 위치 : 남해 배타적 경제수역(EEZ)□ 변경 전 : 6개 광구![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=26419817)□ 변경 후 : 4개 광구![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=26419820) 4. 골재채취단지의 면적 : 10.96㎢ (4개광구) 5. 골재의 부존량![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=26419841) 6. 연도별 채취예정물량□ 변경 전![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=26419844)□ 변경 후 : 변경없음 7. 골재채취허가계획□ 변경 전![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=26419858)□ 변경 후![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=26419861)※ 총 채취량 범위 내에서 연도별 채취량을 변경·운영할 수 있으며 광구별 연간 채취량은 500만㎥ 이내로 운영
