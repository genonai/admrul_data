# 통계작성의 변경승인(협의) 고시(지방세외수입징수실적)
> 고시 · 행정규칙 · 시행 2022-11-06 · 공포 2022-10-31 · 일부개정

### 전문
1. 통계의 명칭 : 지방세외수입징수실적 2. 통계작성기관의 명칭 : 행정안전부 3. 통계작성승인(협의)번호 [작성승인(협의)일] : 제110006호 [1986.12.16.] 4. 통계작성의 변경 연월일 : 2022.10.27. 5. 통계작성의 변경 내용과 사유 :![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=120966335)※ 변경사항(세부사항은 별첨)(추가) 통계표 신규 추가 및 항목 신설제2장 자치단체별 지방행정제재ㆍ부과금 징수현황, 회계별 지방행정제재ㆍ부과금 징수현황,제3장 지방행정제재ㆍ부과금등 징수현황 등(총 26개 항목)(수정) 연번 및 항목 변경제2장 전년대비 징수현황, 단체별ㆍ항목별 징수현황, 자치단체별 임시적 세외수입 징수현황, 회계별 경상적ㆍ임시적 세외수입 징수현황, 회계별 지방행정제재ㆍ부과금등 징수현황, 지난년도 수입의 목별 현황, 특별회계사업별 징수현황, 자치단체별 연도별 신장추세,제3장 시ㆍ도별 전년대비 징수현황, 자치단체 항별 징수현황, 경상적ㆍ임시적 세외수입 징수현황, 특별회계 사업별 자치단체 징수현황, 지난년도 징수현황(시ㆍ도별),제4장 각종 변상금ㆍ과태료ㆍ부담금 징수현황 등(총 54개 항목)(삭제) 연번 삭제제2장 자치단체별 임시적 세외수입 징수현황 중 과징금 등(총 5개 항목)
