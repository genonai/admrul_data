# 전자파적합성 시험방법
> 공고 · 행정규칙 · 시행 2025-08-12 · 공포 2025-07-11 · 일부개정

## 제1장 총칙

### 제1조(목적)
이 시험방법은 [「방송통신기자재등의 적합성평가에 관한 고시」 제4조제3항](https://www.law.go.kr/행정규칙/방송통신기자재등의%20적합성평가에%20관한%20고시/제4조)(이하 "고시"라 한다)에 의하여 전자파적합성 시험방법 등에 관하여 필요한 사항을 규정함을 목적으로 한다.
>
> ↪ 관련(추가): [방송통신기자재등의 적합성평가에 관한 고시](https://www.law.go.kr/행정규칙/방송통신기자재등의%20적합성평가에%20관한%20고시)

### 제2조(적용범위)
이 시험방법은 고시 [제3조](https://www.law.go.kr/행정규칙/전자파적합성%20시험방법/제3조) 규정에 의한 적합성평가 대상기자재의 전자파적합성 시험방법(이하 "적합성 시험"이라 한다)에 적용한다.

## 제2장 세부 시험방법

### 제3조(일반사항에 대한 세부 시험방법)
① 전자파 방해 및 내성 측정 기구의 측정 기구는 KS C 9816-1-1:2022을 적용한다.② 전자파 방해 및 내성 측정 기구의 전도성 방해 측정용 보조 장비는 KS C 9816-1-2:2022을 적용한다.③ 전자파 방해 및 내성 측정기구의 방해전력 측정용 보조 장비는 KS C 9816-1-3:2022을 적용한다.④ 전자파 방해 및 내성 측정 기구의 방사성 방해 측정용 보조 장비는 KS C 9816-1-4:2020을 적용한다.⑤ 전자파 방해 및 내성 측정 기구의 30 MHz ～ 1000 MHz 주파수 대역의 안테나 교정시험장은 KS C 9816-1-5:2023을 적용한다.⑥ 전자파 방해 및 내성 측정 방법의 전도성 방해 측정은 KS C 9816-2-1:2023을 적용한다.⑦ 전자파 방해 및 내성 측정 방법의 방해전력 측정은 KS C 9816-2-2:2020을 적용한다.⑧ 전자파 방해 및 내성 측정 방법의 방사성 방해 측정은 KS C 9816-2-3:2020을 적용한다.⑨ 전자파 방해 및 내성 측정 방법의 내성 측정은 KS C 9816-2-4:2017을 적용한다.⑩ 전자파 방해 및 내성 측정 방법의 대형기기에서 발생한 방해 방출의 현장 측정은 KS C 9816-2-5:2020을 적용한다.⑪ 공공 저압 배전망에서의 고조파 전류 방출 측정은 KS C 9610-3-2:2023/ KS C 9610-3-12:2023을 적용한다.⑫ 공공 저압 배전망에서의 전압변동 및 플리커 측정은 KS C 9610-3-3:2023/ KS C 9610-3-11:2023을 적용한다.⑬ 정전기 방전 내성 시험은 KS C 9610-4-2:2017을 적용한다.⑭ 방사성 RF 전자기장 내성 시험은 KS C 9610-4-3:2017을 적용한다.⑮ 전기적 빠른 과도현상/버스트 내성 시험은 KS C 9610-4-4:2020을 적용한다.<16> 서지 내성 시험은 KS C 9610-4-5:2023을 적용한다.<17> 전도성 RF 전자기장 내성 시험은 KS C 9610-4-6:2020을 적용한다.<18> 전원주파수 자기장 내성 시험은 KS C 9610-4-8:2017을 적용한다.<19> 순간전압 강하 및 순간 정전 내성 시험은 KS C 9610-4-11:2020을 적용한다.<20> 펄스 자기장 내성 시험방법은 KS C 9610-4-9:2019를 적용한다.<21> 공공 저압 배전망에서의 저주파 내성 시험은 KS C 9610-2-2:2024을 적용한다.<22> 산업용 배전망에서의 저주파 내성 시험은 KS C 9610-2-4:2017을 적용한다.

1](https://www.law.go.kr/LSW/admRulBylInfoPLinkR.do?admRulSeq=2100000261680&bylNo=0001&bylBrNo=00)의 KN 62920을 적용한다.③ 의3 산업용 프로그램 제어기 전자파적합성 시험은 KS C IEC 61131-2:2017를 적용한다.③ 의4 보호 계전기 전자파적합성 시험은 KS C 9814-1:2022을 적용한다.⑥ 가정용 전기기기 및 전동기기류에 대한 내성 시험은 KS C 9814-2:2022을 적용한다.⑦ 조명기기류의 장해방지 시험은 KS C 9815:2023을 적용한다.⑧ 조명기기류에 대한 내성 시험은 KS C 9547:2020을 적용한다.⑨ 전기철도기기류의 전자파적합성 시험은 [별표 2](https://www.law.go.kr/LSW/admRulBylInfoPLinkR.do?admRulSeq=2100000261680&bylNo=0002&bylBrNo=00)의 KN 50/KN 51을 적용한다.⑩ 전력선 통신기기류의 장해방지 시험은 KS X 3141:2015를 적용한다.⑪ 무선설비기기류의 전자파적합성 시험은 아래와 같다. 다만, ## 부칙
### 부칙 (공포 2015-12-03 제2015-110호)
