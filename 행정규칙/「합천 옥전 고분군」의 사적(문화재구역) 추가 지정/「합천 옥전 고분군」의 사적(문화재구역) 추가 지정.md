# 「합천 옥전 고분군」의 사적(문화재구역) 추가 지정
> 고시 · 행정규칙 · 시행 2020-04-29 · 공포 2020-04-29 · 제정

### 전문
1. 고 시 명 : 「합천 옥전 고분군」의 사적(문화재구역) 추가 지정가. 대상 문화재1) 종    별 : 사적 제326호 합천 옥전 고분군2) 소 재 지 : 경상남도 합천군 쌍책면 성산리 28번지 등3) 추가 지정면적(지번별 면적조서 붙임) : 30필지 112,852㎡ㅇ 당초 면적 19필지 131,064㎡, 추가 면적 30필지 112,852㎡, 합계 면적 49필지 243,916㎡4) 추가 지정사유 : 지표조사 결과 합천 옥전 고분군의 유구 분포 범위가 확대되고 있어, 합천 옥전 고분군의 문화재 가치 보존, 역사문화환경 보호, 주변지역 정비 등을 위해 문화재구역(지정구역)을 확대하여 보존·관리할 필요성이 있음나. 관리단체 : 경상남도 합천군(합천군수) 2. 추가 지정일 : 관보 고시일 3. 특기사항ㅇ 「토지이용계획 기본법」
제8조(지역·지구등의 지정 등)에 따른 지형도면 등은 ‘문화재공간정보(GIS)서비스(http://www.gis-heritage.go.kr) 알림마당-지형도면고시’에서 열람이 가능하고, ‘경상남도 가야문화유산과’ 및 ‘합천군 문화예술과’, ‘문화재청 보존정책과’에 관계도서를 비치하여 이해관계인에게 보이고 있습니다. 4. 연 락 처가. 문화재청ㅇ 문화재청 보존정책과 : 전화 042-481-4842 / 팩스 042-481-4849- 주    소 : (우 35208) 대전광역시 서구 청사로 189 정부대전청사 1동- 홈페이지 : http://www.cha.go.kr나. 지방자치단체ㅇ 경상남도 가야문화유산과 : 전화 055-211-4563 / 팩스 055-211-4559- 주소 (51430) 경상남도 창원시 의창구 용지로 248ㅇ 합천군 문화예술과 : 055-930-3181 / 팩스 055-930-3179- 주소 (50235) 경상남도 합천군 합천웁 동서로 119 ![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=64480755)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=64480759)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=64480763)
