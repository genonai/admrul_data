# 국가무형문화재 명예보유자 인정(고성농요)
> 고시 · 행정규칙 · 시행 2023-05-12 · 공포 2023-05-12 · 제정

### 전문
1. 고 시 명 : 국가무형문화재 고성농요 명예보유자 인정 2. 고시내용![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=128143479) 3. 인 정 일 : 관보 고시일 4. 인정사유ㅇ 국가무형문화재 고성농요 보유자 김석명은 그동안 해당 종목의 전승을 위하여 헌신해왔으나, 최근 건강상의 이유로 정상적인 전수교육 및 전승활동이 어려워 명예보유자로 인정 함
