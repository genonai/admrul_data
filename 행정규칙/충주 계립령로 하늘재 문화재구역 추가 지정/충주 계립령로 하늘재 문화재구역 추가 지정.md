# 충주 계립령로 하늘재 문화재구역 추가 지정
> 고시 · 행정규칙 · 시행 2016-11-14 · 공포 2016-11-14 · 일부개정

### 전문
1. 고 시 명 : 「충주 계립령로 하늘재」문화재구역 추가 지정 2. 고시사항가. 대상문화재 : 명승 제49호 「충주 계립령로 하늘재」ㅇ 소재지 : 충청북도 충주시 수안보면 미륵리 산16-1번지 등나. 문화재구역 추가지정 면적 : 38,672㎡, 4필지![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=27432761)다. 추가지정 후 문화재구역 면적ㅇ (추가지정 전) 397,478㎡, 34필지 → (추가지정 후) 436,150㎡, 38필지「충주 계립령로 하늘재」문화재구역 추가지정 후 지번별 면적조서![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=27432764)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=27432765)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=27432766)라. 추가 지정 사유ㅇ 문화재 지정(’08.12.26) 고시 당시 문화재구역 목록에서 누락된 4필지(토지이용계획 등 지형도면에는 문화재 지정구역으로 표기됨)를 문화재의 효율적인 보존관리를 위해 지정구역에 포함하고자 함마. 문화재 관리단체 : 충주시(충주시장)바. 지형도면 : 붙임과 같음 3. 추가 지정일 : 관보 고시일 4. 특기사항ㅇ[「토지이용규제기본법」
제8조](https://www.law.go.kr/법령/토지이용규제기본법/제8조)(지역·지구 등의 지정)에 따른 지형도면 등은 ‘문화재공간정보(GIS) 서비스(http://www.gis­heritage.go.kr) 알림마당-지형도면고시’에서 열람이 가능합니다. 5. 연락처가. 문화재청ㅇ 문화재청 문화재보존국 천연기념물과 : 전화 042-481-4993 / 팩스 042-481-4999ㅇ 주    소 : (우 35208) 대전광역시 서구 청사로 189 정부대전청사 1동ㅇ 홈페이지 : http://www.cha.go.kr나. 문화재 관리단체ㅇ 충주시 문화예술과 : 전화 043-850-5981 / 팩스 043-850-5999ㅇ 주  소 : (우 27339) 충북 충주시 으뜸로 21
