# 수질오염물질 배출허용기준 중 별도배출허용기준 지정·고시(영암 특화)
> 고시 · 행정규칙 · 시행 2018-01-18 · 공포 2018-01-18 · 일부개정

### 전문
영암특화농공단지 내 배출시설에서 배출되는 폐수를 배수설비를 통하여 영암공공하수처리시설에 전량 유입하는 경우에는, 해당 배출시설에서 배출되는 수질오염물질의 배출허용기준을 다음과 같이 정한다.![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=33315679)
