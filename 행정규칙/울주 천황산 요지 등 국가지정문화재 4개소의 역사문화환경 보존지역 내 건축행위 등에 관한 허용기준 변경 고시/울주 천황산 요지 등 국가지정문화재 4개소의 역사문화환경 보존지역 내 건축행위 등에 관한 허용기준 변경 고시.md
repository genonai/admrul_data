# 울주 천황산 요지 등 국가지정문화재 4개소의 역사문화환경 보존지역 내 건축행위 등에 관한 허용기준 변경 고시
> 고시 · 행정규칙 · 시행 2016-12-30 · 공포 2016-12-30 · 일부개정

### 전문
1. 고 시 명 : 「울주 천황산 요지」등 국가지정문화재 4개소의 역사문화환경 보존지역 내 건축행위 등에 관한 허용기준 변경 고시 2. 고시사항가. 대상문화재![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=28677114)나. 관련근거ㅇ 문화재보호법 제13조, [제35조제1항제2호](https://www.law.go.kr/법령/문화재보호법/제35조)ㅇ 문화재보호법 시행령 [제21조의2제2항](https://www.law.go.kr/법령/문화재보호법%20시행령/제21조의2)ㅇ 문화재보호법 시행규칙 [제2조의2](https://www.law.go.kr/법령/문화재보호법%20시행규칙/제2조의2)다. 기준의 적용ㅇ 본 허용기준은 [「문화재보호법」제13조제4항 및 제6항](https://www.law.go.kr/법령/문화재보호법/제13조)과 [같은 법 시행령](https://www.law.go.kr/법령/문화재보호법%20시행령) [제21조의2제2항제1호](https://www.law.go.kr/법령/문화재보호법%20시행령/제21조의2)의 행위를 대상으로 한정하며, 그 이외의 사항에 대해서는 현행과 같은 국가지정문화재 현상변경 등 행위 처리절차에 따라 처리함ㅇ 본 허용기준 범위 내 행위는 [「문화재보호법」 제13조제2항](https://www.law.go.kr/법령/문화재보호법/제13조), 제6항에 따라 역사문화환경 보존지역에서 지정문화재의 보존에 영향을 미칠 우려가 없는 행위이므로 문화재 영향검토를 생략하고, 지방자치단체에서 자체 처리함라. 역사환경 보존지역 내 건축행위 등에 관한 허용기준ㅇ 세부내용 별첨자료 참조ㅇ 문화재별 현상변경 허용기준 도면- 문화재청 홈페이지(www.cha.go.kr) : 행정정보 > 법령정보 > 고시- 문화재공간정보(GIS)서비스(http://gis-heritage.go.kr) : 알림마당 > 현상변경 허용기준 3. 기준시행일 : 관보 고시일 4. 연 락 처가. 문화재청ㅇ 문화재청 문화재보존국 보존정책과 : 전화 042-481-4847 / 팩스 042-481-4849- 주소 : (우 35208) 대전광역시 서구 청사로 189 정부대전청사 1동- 홈페이지 : http://www.cha.go.kr나. 지방자치단체ㅇ 울산광역시 문화예술과 : 전화 052-229-3733/팩스 052-229-3719- 주    소 : (우 44675) 울산광역시 남구 중앙로 201(신정동)- 홈페이지 : http://www.ulsan.go.krㅇ 울산광역시 울주군 문화관광과 : 전화 052-229-7652/팩스 052-229-7639- 주    소 : (우 44663) 울산광역시 남구 문수로 382(옥동)- 홈페이지 : http://www.ulju.ulsan.go.krㅇ 강원도 문화예술과 : 전화 033-249-3315 /팩스 033-249-4057- 주소 : (우 24266) 강원도 춘천시 중앙로1(봉의동)- 홈페이지 : http://www.provin.gangwon.krㅇ 강원도 영월군 문화관광체육과 : 전화 033-370-2100 /팩스 033-370-2540- 주소 : (우 26235) 강원도 영월군 영월읍 하송로 64- 홈페이지 : http://www.yw.go.krㅇ 강원도 삼척시 문화공보실 : 전화 033-570-3723 /팩스 033-570-3132- 주소 : (우 25914) 강원도 삼척시 중앙로 296(교동, 삼척시청)- 홈페이지 : http://samcheok.go.kr
