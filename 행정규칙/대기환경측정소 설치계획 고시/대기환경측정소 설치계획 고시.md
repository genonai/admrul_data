# 대기환경측정소 설치계획 고시
> 고시 · 행정규칙 · 시행 2022-07-07 · 공포 2022-07-07 · 제정

### 전문
1. 측정소명 : 김천시 대광동 유해대기물질측정소 2. 대기오염측정망 종류 : 유해대기물질측정망 3. 측정소 설치시기 : 2022년 10월 이후(예정) 4. 측정소 배치도 : "게재생략" 5. 측정소를 설치할 토지 또는 건축물의 위치 및 면적![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=119033841) 6. 측정소 배치도 열람장소 및 기간가. 열람장소 : 한국환경공단 대구경북지역본부 대기관리부(053-280-3821)나. 열람기간 : 고시일부터 30일 이내
