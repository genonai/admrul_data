# 「산청 목면시배유지」의 문화재구역 조정 지정
> 고시 · 행정규칙 · 시행 2020-04-29 · 공포 2020-04-29 · 제정

### 전문
1. 고 시 명 : 「산청 목면시배유지」의 문화재구역 조정 지정가. 대상 문화재1) 종    별 : 사적 제108호 산청 목면시배유지2) 소 재 지 : 경상남도 산청군 단성면 사월리 106-1번지 등3) 조정 지정면적(지번별 면적조서 붙임) : 지정구역 8필지 3,111㎡ / 보호구역 19필지 11,753㎡4) 조정 지정사유 : 문화재의 효율적 보존·관리를 위해 지정구역과 보호구역 전반을 조정하여 지정함나. 관리단체 : 경상남도 산청군(산청군수) 2. 조정 지정일 : 관보 고시일 3. 특기사항ㅇ 「토지이용계획 기본법」
제8조(지역·지구등의 지정 등)에 따른 지형도면 등은 ‘문화재공간정보(GIS)서비스(http://www.gis-heritage.go.kr) 알림마당-지형도면고시’에서 열람이 가능하고, ‘경상남도 가야문화유산과’ 및 ‘산청군 문화체육과’, ‘문화재청 보존정책과’에 관계도서를 비치하여 이해관계인에게 보이고 있습니다. 4. 연 락 처가. 문화재청ㅇ 문화재청 보존정책과 : 전화 042-481-4842 / 팩스 042-481-4849- 주    소 : (우 35208) 대전광역시 서구 청사로 189 정부대전청사 1동- 홈페이지 : http://www.cha.go.kr나. 지방자치단체ㅇ 경상남도 가야문화유산과 : 전화 055-211-4563 / 팩스 055-211-4559- 주소 (51430) 경상남도 창원시 의창구 용지로 248ㅇ 산청군 문화체육과 : 055-970-6412 / 팩스 055-970-6409- 주소 (52221) 경상남도 산청군 산청읍 산엔청로 1 ![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=64480059)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=64480063)
