# 「강화 곤릉」보호구역 조정
> 고시 · 행정규칙 · 시행 2020-10-06 · 공포 2020-10-06 · 일부개정

### 전문
1. 고 시 명 :「강화 곤릉」보호구역 조정 2. 고시사항가. 대상문화재 : 사적 제371호「강화 곤릉」ㅇ 소재지 : 인천광역시 강화군 양도면 길정리 산75 외나. 보호구역 조정 내용ㅇ 당초 : 문화재구역 4필지 1,572㎡  / 보호구역 없음ㅇ 조정 후 : 문화재구역 4필지 1,572㎡ / 보호구역 4필지 94,688㎡(순증)다. 보호구역 조정 사유ㅇ 강화 곤릉 방문의 출발지로 향후 종합정비계획 수립에 따른 주차장 및 안내소 등 관람편의시설 조성이 필요한 지역으로 문화재보호구역 지정이 필요함 3. 기준시행일 : 관보 고시일 4. 특기사항ㅇ[「토지이용규제 기본법」
제8조](https://www.law.go.kr/법령/토지이용규제%20기본법/제8조)(지역·지구등의 지정 등)에 따른 지형도면 등은 ‘문화재공간정보(GIS) 서비스(http://www.gis-heritage.go.kr)알림마당-지형도면고시’에서 열람이 가능합니다. 5. 연 락 처가. 문화재청ㅇ 문화재청 문화재보존국 보존정책과 : 전화 042-481-4837 / 팩스 042-481-4849- 주소 : (우 35208) 대전광역시 서구 청사로 189, (둔산동, 정부대전청사 1동)- 홈페이지 : http://www.cha.go.kr나. 지방자치단체ㅇ 인천광역시 문화재과 : 전화 032-440-4470 / 팩스 032-440-8693- 주    소 : (우 21544) 인천광역시 남동구 정각로 29- 홈페이지 : www.incheon.go.krㅇ 강화군 문화관광과 : 전화 032-930-3893 / 팩스 032-930-3632- 주소 : (우 23031) 인천광역시 강화군 강화읍 강화대로 394- 홈페이지 : http://www.ganghwa.go.kr
