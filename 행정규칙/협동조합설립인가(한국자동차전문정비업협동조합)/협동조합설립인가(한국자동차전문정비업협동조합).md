# 협동조합설립인가(한국자동차전문정비업협동조합)
> 공고 · 행정규칙 · 시행 2009-06-02 · 공포 2009-06-02 · 제정

### 전문
가. 인가번호 : 제 259 호나. 조 합 명 : 한국자동차전문정비업협동조합다. 소 재 지 : 서울특별시 금천구 가산동 470-5 에이스테크노타워10차304호라. 대 표 자 : 조 재 호마. 인 가 일 : 2009. 6. 2.바. 업무구역 : 전국사. 업종구분 : 자동차전문수리업[한국표준산업분류 95212]------------------------------------------------------------------------------------------------가. 인가번호 : 제 260 호나. 조 합 명 : 한국군납물류업협동조합다. 소 재 지 : 서울특별시 송파구 문정동 78-18라. 대 표 자 : 김 진 우마. 인 가 일 : 2009. 6. 2.바. 업무구역 : 전국사. 업종구분 : 군납물류업[한국표준산업분류 4610]. 끝.
