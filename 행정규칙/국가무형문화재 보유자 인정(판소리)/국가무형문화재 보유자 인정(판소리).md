# 국가무형문화재 보유자 인정(판소리)
> 고시 · 행정규칙 · 시행 2021-08-23 · 공포 2021-08-23 · 제정

### 전문
1. 고 시 명 : 국가무형문화재 ‘판소리(고법)’ 보유자 인정 2. 고시내용![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=107097293) 3. 인 정 일 : 관보 고시일 4. 인정사유ㅇ 박시양은 국가무형문화재 판소리(고법) 종목의 전승능력, 전승환경, 전수활동 기여도 등이 탁월하여 국가무형문화재 판소리 보유자로 인정함.
