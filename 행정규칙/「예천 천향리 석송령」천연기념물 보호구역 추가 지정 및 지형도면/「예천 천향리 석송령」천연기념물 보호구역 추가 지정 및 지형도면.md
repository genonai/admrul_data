# 「예천 천향리 석송령」천연기념물 보호구역 추가 지정 및 지형도면
> 고시 · 행정규칙 · 시행 2017-11-08 · 공포 2017-11-08 · 일부개정

### 전문
1. 고 시 명 : 「예천 천향리 석송령」천연기념물 보호구역 추가 지정 및 지형도면 2. 고시사항가. 대상문화재 : 천연기념물 제294호 「예천 천향리 석송령」ㅇ 소 재 지 : 경상북도 예천군 감천면 천향리 804 등나. 보호구역 추가 지정 면적 : 940㎡(1필지)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=32178305)다. 추가지정 후 보호구역 면적 : 3,926㎡(8필지)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=32178310)라. 보호구역 추가 지정 사유ㅇ 예천 천향리 석송령 출입구 주변의 녹지대로, 문화재 보존·관리 및 후계목 보호 등을 위하여 보호구역을 확대하고자 함마. 관리단체 : 예천군바. 지형도면 : 붙임과 같음 3. 추가 지정일 : 관보 고시일 4. 특기사항 : 토지이용규제기본법 [제8조](https://www.law.go.kr/법령/토지이용규제기본법/제8조)에 따른 지형도면 등은 문화재공간정보(GIS)서비스(http://www.gis­heritage.go.kr)에서 열람이 가능하고, 문화재청 천연기념물과와 예천군청 문화관광과에서 출력된 도면을 열람하실 수 있습니다. 5. 연락처가. 문화재청ㅇ 주  소 : (우)35208 대전광역시 서구 청사로 189ㅇ 연락처 : 문화재청 천연기념물과 (전화) 042-481-4988, (전송) 042-481-4999ㅇ 홈페이지 : http://www.cha.go.kr, 전자메일 litston@korea.kr나. 지방자치단체ㅇ 주  소 : (우)36822 경상북도 예천군 예천읍 군청길 33ㅇ 연락처 : 예천군청 문화관광과 (전화) 054-650-6906, (전송) 054-650-6399ㅇ 홈페이지 : http://www.ycg.kr, 전자메일 mideng@korea.kr
