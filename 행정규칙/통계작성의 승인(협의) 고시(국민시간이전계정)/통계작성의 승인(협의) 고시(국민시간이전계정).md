# 통계작성의 승인(협의) 고시(국민시간이전계정)
> 고시 · 행정규칙 · 시행 2026-06-17 · 공포 2026-06-11 · 제정

### 전문
1. 통계의 명칭 : 국민시간이전계정 2. 통계작성기관의 명칭 : 국가데이터처 3. 통계작성승인(협의)번호 [작성승인(협의)일] : 제101095호 [2026.06.05.] 4. 통계작성의 목적 : 시장 부문의 자원 배분 통계인 국민이전계정과 비시장 부문을 통합하여 분석하기 위해 가계생산위성계정 연령별로 배분하여 작성   - 국민이전계정과 함께 세대 간 자원 배분을 종합적으로 제시 5. 통계작성의 대상    - 대상 : 개인/개인   - 모집단 : 해당 없음(가공통계)   - 대상 범위 및 규모 : 대한민국 전체 국민   - 대상지역 : 전국 6. 통계작성의 주기 : 5년 7. 통계작성의 방법 : 가공통계/일반통계
